# Building Transformer from Scratch

This project contains implementations and experiments for learning how transformer and language models work from first principles.

## Files

- `transformer_from_scratch.py` - annotated transformer implementation in PyTorch.
- `train_model_biagram.ipynb` - character-level language-model training notebook.
- `input.txt` - text corpus used by the notebook.
- `train.py` - training-script placeholder.

## Run

Install PyTorch, then run:

```bash
python transformer_from_scratch.py
```

Open `train_model_biagram.ipynb` in Jupyter to work through the notebook experiment.
